# 语义中心点标注约定

顶层字段：`classes`是固定的输出通道顺序，`images`是图片记录。浏览器标注包另有`schema`、`kit_id`、`class_definitions`、相机顺序与轨迹信息。导入时项目身份、图片身份和类别顺序必须相同。

每张图保留：

- 唯一`id`、相对于图片根目录的`file_name`、原始`width/height`。
- `episode_index`、`frame_index`、`camera`和固定`split`。
- `rgb_sha256`用于防止错图；原HDF5路径与数据键仅作溯源。
- `reviewed`以及每个类别的`status/point_xy`。

坐标：原始图像像素，左上角为原点，x向右、y向下。网络输入缩放/几何增强时同步变换坐标；各相机的坐标分别判断，不能用另一视角猜当前图隐藏点。

硬币标圆面几何中心；投币槽标黑色开口中点。部分物体可见不代表指定中心可见。空支架、反光、夹爪不能代替硬币。侧视不能确定圆面投影中心时选忽略。

`visible`必须有有效坐标；`not_visible/ignore/pending`必须为null。已完成图不能含pending。模型候选未人工确认前保持reviewed=false，不进入训练。

验证标签复核是数据版本修订，不是增加训练样本。保留原导出，记录更改项，并在相同修订真值上同时重算新旧模型；禁止用验证复核图做梯度更新。

一类多个实例、物体分割、三维姿态、动作阶段和接触判断不由这个单点输出格式完整表达，需要另外设计标注与输出。

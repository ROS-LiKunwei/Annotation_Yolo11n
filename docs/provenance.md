# 来源、迁移范围与实验结果

核心网络和损失来自deposit_coin的R4实验实现`heatmap_experiment.py`，独立推理来自`heatmap_runtime.py`，人工页面源于原离线中心点标注模板。当前仓库重构为显式路径参数、可配置类别数及可安装Python包。

网络层与state_dict键名保留，包括layers、p2、semantic、fuse、heatmap、visibility，可以读取已有R4空间权重。旧推理包的双腕可见性组合也保留兼容。训练入口使用独立模型与开发验证选择；原R4完整实验还包含任务微调后的R3共享YOLO初始化以及跨检查点/可见性组合选择。默认从通用YOLO权重开始的训练不能保证复现同一数值。

硬币实验共有378张已核验人工标注，训练312张/24条轨迹、开发验证66张/6条轨迹。按原图误差≤10像素且分数≥0.5，原标签下R3准确率61.1%、召回率57.1%，R4为96.0%、93.5%。之后人工复核6张验证图，修订空支架误认、侧视几何中心和可见状态；固定模型、固定预测与路由，在相同修订标签上重算，R3为63.9%、60.5%，R4为100.0%、98.7%。

这些是反复用于方法/检查点/路由选择的开发数据，复核图也根据残余错误挑选，不能视为独立测试或其他任务性能保证。训练/验证轨迹与图像哈希分离，保留测试轨迹未参与训练。

该仓库发布源代码、合成格式示例与结构图。真实RGB、人工导出、模型权重、工作站路径配置、SSH凭据和VLM20k训练数据保留在外部。
